# Local Development Setup Instructions

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (comes with Node.js)
- A code editor like VS Code

---

## Step 1: Copy the Project

Copy the entire project folder to your local machine.

## Step 2: Install Dependencies

Open a terminal in the project root and run:

```bash
npm install
```

This will generate the `node_modules/` folder with all required packages.

## Step 3: Set Up Environment Variables

Create a `.env` file in the project root with your own Supabase credentials:

```env
VITE_SUPABASE_PROJECT_ID="your-supabase-project-id"
VITE_SUPABASE_PUBLISHABLE_KEY="your-supabase-anon-key"
VITE_SUPABASE_URL="https://your-project-id.supabase.co"
```

> If you don't have a Supabase project, create one for free at [supabase.com](https://supabase.com). You'll find these values in your Supabase dashboard under **Settings → API**.

## Step 4: Run the Dev Server

```bash
npm run dev
```

The app will start at **http://localhost:8080**

> ⚠️ **Do NOT use VS Code's "Live Server" extension.** This is a Vite + React project and must be run with `npm run dev`.

---

## Files You DON'T Need to Copy

| File/Folder | Reason |
|---|---|
| `node_modules/` | Regenerated by `npm install` |
| `bun.lock` / `bun.lockb` / `package-lock.json` | Regenerated on install |
| `.env` | Contains Lovable Cloud credentials — create your own |

## Files You MUST Keep

Everything else — all `src/`, `public/`, `supabase/`, config files (`vite.config.ts`, `tailwind.config.ts`, `tsconfig.json`, `package.json`, etc.)

---

## Supabase Setup (Backend)

This project uses Supabase for:

- **Authentication** (login, signup, password reset)
- **Database** (profiles, contact_messages tables)
- **Storage** (avatar uploads)
- **Edge Functions** (account deletion)

To replicate the backend, create the required tables in your Supabase project by running the SQL migrations found in `supabase/migrations/`.

---

## Build for Production

```bash
npm run build
```

The output will be in the `dist/` folder, which can be deployed to any static hosting service (Vercel, Netlify, Cloudflare Pages, etc.).
